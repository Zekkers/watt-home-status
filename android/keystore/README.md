# Family sideload keystore

This keystore is for installing **Watt Home** on Ian and family’s phones only.
It is **not** a Play Store / production signing secret.

- File: `watt-family.jks`
- Alias: `watt-family`
- Store password / key password: `watt-home-family`
- Validity: 10,000 days

Keep using this same keystore for later APKs so the two phones can update without uninstalling.
